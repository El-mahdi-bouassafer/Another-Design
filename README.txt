ANOTHER DESIGN — Website project

Contents
- docs/: all 13 website pages, CSS, JavaScript and images, ready to host.
- build.py: optional Python script that regenerates the HTML pages.

Preview locally
1. Open Terminal in this project folder.
2. Run: python3 -m http.server 8000 --directory docs
3. Open http://localhost:8000

Hosting
Upload the contents of docs/ to the root of a static website host.
The site uses root-relative links, so use a web server rather than double-clicking HTML files.
No npm installation or build is required.

The contact form prepares a WhatsApp message for the visitor to review and send.
